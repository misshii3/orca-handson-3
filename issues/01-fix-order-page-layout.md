# 注文確認ページの見た目の崩れを直す（合計金額・金額列・お届け日・スマホ幅のボタン）

## 背景

`npm run dev` で起動する注文確認ページ（`public/`）に、見た目の崩れが 4 か所あります。
原因は `public/style.css` と `public/app.js` にあり、どれも 1〜3 行の修正で直ります。

ページは Orca のブラウザで `http://localhost:3000` を開いて確認します。
dev サーバーは参加者がすでに起動しています。**エージェントは dev サーバーを起動・停止・再起動しないでください**（`npm run dev`、`kill`、`lsof` を実行しない）。

## 崩れている箇所と期待する見た目

| # | 場所（要素） | 今の状態 | 期待する見た目 |
|---|---|---|---|
| 1 | 「合計（税込）」の金額 `#total` | 文字色が背景と同じ白で読めない | 強調色（CSS 変数 `--color-accent`）ではっきり読める |
| 2 | 商品テーブルの数量・単価・金額の列 `.items-table .col-num` | 左寄せ | 見出し（`th`）も含めて右寄せ |
| 3 | お届け予定日 `#delivery-date` | `2026-09-18` のような ISO 表記 | 「2026年9月18日」の日本語表記（`src/date.js` の `formatDateJa` を使う） |
| 4 | 「注文を確定する」ボタン `#confirm-button`（幅 375px で確認） | カードの右端からはみ出す | カードの内側に収まり、カードの幅いっぱいに広がる |

## 仕様

- 変更するファイルは `public/style.css` と `public/app.js` の 2 つだけ。`public/index.html`、`src/`、`test/` は変更しない
- 3 は `public/app.js` の `renderDelivery` で、**表示文字だけ** `formatDateJa` にする。`<time>` の `datetime` 属性は機械が読む `YYYY-MM-DD`（`formatDate`）のまま残す
- 色やサイズの細かい値は、参加者が Design Mode で要素を送るときにメモで指示する。メモがなければ上の表の期待どおりに、**既存の CSS 変数とクラス** を使って直す
- 新しい CSS 変数・クラス・id は追加しない。既存のルールを直すか、1〜3 行足す
