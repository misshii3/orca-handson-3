# クーポン入力欄を追加する（コードを入力すると割引と合計が再計算される）

## 背景

注文確認ページ（`public/`）のクーポンは、今は `public/app.js` の `INITIAL_COUPON_CODE`（`WELCOME10`）が固定で適用されています。
お客さまが自分でコードを入力して適用できるように、入力欄と「適用」ボタンを追加します。
割引の計算は既存の `applyCoupon`（`src/price.js`）を **そのまま** 使い、`src/` は変更しません。

dev サーバーは参加者がすでに起動しています（`http://localhost:3001`）。**エージェントは dev サーバーを起動・停止・再起動しないでください**（`npm run dev`、`kill`、`lsof` を実行しない）。

## 仕様

### 画面（`public/index.html`）

- 「お支払い金額」カードの `<!-- Issue #2: クーポン入力欄はここに追加する -->` の位置（お届け予定日の下、「注文を確定する」ボタンの上）に追加する
  - `<form id="coupon-form">` の中に、`<label>`「クーポンコード」付きのテキスト入力 `<input id="coupon-input" type="text">` と、`<button id="coupon-apply" type="submit">適用</button>`
  - 結果メッセージ用の `<p id="coupon-message" role="status"></p>`（初期状態は空）
- 入力欄の初期値は、現在適用中のコード（`INITIAL_COUPON_CODE`）

### 動き（`public/app.js`）

- 「適用」を押す（または入力欄で Enter）と、入力値の前後の空白を除いたものをコードとして扱う
- コードが `COUPONS` にあるとき: `render(code)` で割引・送料・合計を再計算し、メッセージに「クーポン「SAVE500」を適用しました」と出す
- コードが `COUPONS` にないとき: `render("")`（クーポンなし）で再計算し、メッセージに「クーポンコード「ABC」は使えません」と出す。割引の行は「クーポン割引（なし）」になる
- 空欄のとき: 再計算せず、メッセージに「クーポンコードを入力してください」と出す
- 大文字・小文字は区別する（`welcome10` は無効）
- 既存の関数（`calcOrder`, `renderItems`, `renderSummary`, `renderDelivery`, `render`）と `import` 行は変更しない。新しい処理は `public/app.js` の **末尾** に `setupCouponForm()` として追加し、末尾の初期化部分（`// Issue #2:` のコメントの下）から呼ぶ
- スタイルは `public/style.css` の **末尾**（`/* ---- ここから下に新しいスタイルを追加する` の下）に追加する。既存のルールは変更しない

### 具体例（商品は変えない。小計 3,300 円）

| 入力 | 割引の行 | 送料 | 合計（税込） | メッセージ |
|---|---|---|---|---|
| `WELCOME10`（初期状態と同じ） | クーポン割引（WELCOME10） −330 円 | 500 円 | 3,817 円 | クーポン「WELCOME10」を適用しました |
| `SAVE500` | クーポン割引（SAVE500） −500 円 | 500 円 | 3,630 円 | クーポン「SAVE500」を適用しました |
| `ABC` | クーポン割引（なし） 0 円 | 無料 | 3,630 円 | クーポンコード「ABC」は使えません |
| （空欄） | 変わらない | 変わらない | 変わらない | クーポンコードを入力してください |

`SAVE500` と無効コードの合計が同じ 3,630 円になるのは偶然ではなく、500 円引きで 3,000 円を下回ると送料 500 円がかかるためです。
